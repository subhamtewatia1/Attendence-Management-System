

# Expense, Attendance, Grading & Billing Management System

A Python-based, menu-driven console application for managing expenses, attendance, student grades, and customer bills.

## Project Files

- **`main.py`** – Displays the main menu, accepts user choices, and runs the application.
- **`functions.py`** – Contains reusable functions for input validation, calculations, module operations, and report generation.

## Features

- **Expense Management:** Add and view expenses, calculate category-wise totals, and identify the highest and lowest expenses.
- **Attendance Management:** Record attendance, calculate percentages, and assign Eligible, Warning, or Shortage status.
- **Grading System:** Enter subject marks, calculate totals and averages, assign grades, and determine pass/fail results.
- **Billing System:** Add bill items, calculate subtotals, apply discount slabs, and calculate 18% tax.
- **Reports:** Display module summaries and export report details to a text file.

## Requirements

- Python 3.8 or later
- Python standard library only
- No external packages required

## Run the Application

Keep `main.py` and `functions.py` in the same folder. Open a terminal in that folder and run:

```bash
python main.py
```

## Data Handling

Records are stored in memory during execution and are cleared when the application closes. Exported text reports remain saved separately.
